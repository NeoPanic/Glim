# Accessibility

Glim aims to make files easier to read, including through selectable text, search, and adjustable reading layouts. Settings includes a macOS Keyboard Shortcuts reference. The main workspace provides keyboard shortcuts and a word-wrap toggle; Markdown and HTML can be read as source or rendered content.

Current desktop builds target macOS (Apple Silicon and Intel). Full VoiceOver, keyboard-only navigation, high-contrast, and reduced-motion coverage has not yet been validated. We do not currently claim conformance to an accessibility standard. Native preview windows depend in part on operating-system controls.

Please [report an accessibility barrier](https://github.com/glimapp/glim/issues/new?template=bug_report.yml) with the app version, operating system, assistive technology, task, and expected behavior. Sanitized examples are welcome; no medical or personal information is needed. English and Chinese reports are welcome.
