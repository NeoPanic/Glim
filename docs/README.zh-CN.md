# Glim 文档

[English](README.md) · **简体中文** · [产品首页](../README.zh-CN.md) · [下载](https://github.com/glimapp/glim/releases/latest)

Glim 是 macOS 上的文件阅读工作空间，将文档、数据、图片和代码放在同一个窗口中。支持 Apple Silicon 与 Intel。
