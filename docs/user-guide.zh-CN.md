# 使用 Glim

[English](user-guide.md) · **简体中文** · [文档目录](README.zh-CN.md)

Glim 将文档、数据和代码放在一个 Mac 工作空间中。可以从已有的文件夹开始：一份报告、相关图片、导出数据，以及生成它们的脚本。

## 打开与查找文件

- **⌘O** 打开文件，**⌘⇧O** 打开文件夹。“添加文件夹到工作空间”可在当前窗口中追加文件夹。
- 侧栏包含主页与工作空间文件树。主页提供打开操作和最近的文件夹工作空间；收起后保留窄图标栏，点击文件夹图标可重新展开文件列表。
- 标题栏搜索按名称或路径查找工作空间文件夹中的文件，受文件发现范围约束，不搜索文件正文。编辑文档中的文字可通过源码编辑器搜索。
- 文件在标签中打开。再次打开已有文件会激活对应标签或窗口；后退／前进可回到先前打开的文件。
- **⌘W** 关闭当前标签或空窗口，**⌘⇧W** 关闭当前窗口。关闭最后一个窗口后 Glim 仍运行，**⌘Q** 退出应用。

## 选择阅读视图

Markdown 和 HTML 提供预览与原文视图。Markdown 可排版表格、公式和图表，通过本地链接打开相关文件。HTML 使用 WebKit，支持 CSS、JavaScript 和网络资源；相对本地资源限定在所属项目内，未找到项目根目录时限定在文档目录内。

JSON 系列文件提供只读树和原文；CSV/TSV 提供只读表格和可编辑原文，单元格显示不全时可查看完整值。支持的结构化格式还可投影为交互图，切换视图不会修改文件。

PDF、图片、支持的 Office 文档、电子书和媒体各有阅读控件。操作按阅读器能力出现在外围工具栏、内容悬浮工具栏或内容菜单中。带悬浮工具栏的阅读器，可将指针停留在内容底部附近以显示控件。快捷键说明位于**设置 → 键盘快捷键**。文件全屏为当前内容腾出空间，Escape 返回工作空间。

各格式的操作与兼容范围见[格式说明](file-format-support.zh-CN.md)。部分预览只呈现格式的一部分能力，专业编辑或原始排版可交给默认应用。

## 编辑与保存文本

普通 UTF-8 文本支持输入、选择、撤销重做和 **⌘S** 显式保存。已有文件在停止输入片刻后自动保存，写入的是原文件，查看配置或共享文件时请留意这一行为。若保存前磁盘内容发生变化，Glim 会保留编辑器中的未保存内容并提示冲突。

**⌘N** 创建未命名文本笔记。第一次保存时选择文件名和位置，此后的修改沿用自动保存。更改扩展名不会将文本转换成 PDF、图片或 Office 文档。

大文本或超长行 UTF-8 文件使用可编辑分页；需要时按提示先保存当前页再翻页。生成文本、二进制视图、数据库快照、图片和文档预览保持只读，只有支持编辑的格式提供原文编辑。

关闭未保存内容前，可选择保存、不保存或取消；保存失败或取消保存后，笔记仍保持打开。

## 只读浏览 SQLite

Glim 创建独立快照，包含存在的关联 WAL／journal 数据，并检查复制期间源状态是否稳定。打开主数据库文件，选择表或视图，搜索全部记录的所有字段、排序或翻页；双击单元格可阅读完整值，耗时查询可提供延长时间后重试的入口。

快照为只读，不执行任意写入 SQL，也不 checkpoint 源数据库。暂不支持加密数据库。

## 继续上次工作

主页显示最近的文件夹工作空间，重新打开时恢复目录。普通启动尚不恢复全部文件标签及各阅读器的滚动／播放位置；电子书单独保存书签和阅读进度。

未命名笔记会在本地保存恢复检查点，中断会话后可恢复。尚未写入检查点的修改仍可能丢失，恢复失败时会提示；重要笔记应保存为具名文件。笔记检查点与完整工作空间会话恢复分别管理。

已配置的应用内更新可通过一次性重启检查点恢复支持的文件／播放列表标签，见[更新行为](auto-update-design.zh-CN.md)。具体发布版本的能力以更新说明为准。

## 设置、联网内容与求助

设置提供外观、语言、默认文件类型关联、检查更新、快捷键帮助及可选的匿名使用统计。本地文件阅读不依赖托管查看服务；Markdown 远程图片、HTML 网络内容，以及启用的更新／统计请求可能联网，见[统计说明](telemetry.zh-CN.md)和[安全政策](../SECURITY.md)。

文件无法打开或预览不正确时，可[报告问题](https://github.com/glimapp/glim/issues/new?template=bug_report.yml)，附 Glim 版本、macOS 版本、文件格式、操作步骤，以及可以分享的脱敏样例。不要提交凭据或私密文档／数据库内容。部分错误页提供重试或打开日志文件夹；日志可能包含本地路径，分享前请检查。
