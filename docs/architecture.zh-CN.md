# 架构

[English](architecture.md) · **简体中文** · [文档目录](README.zh-CN.md)

专注于 macOS 的文件查看器。阅读器共用标签工作台；普通 UTF-8 文本支持基础编辑和自动保存，差异、历史内容、图片及二进制／文档预览保持只读。

## 阅读器悬浮操作条

`reader/controls` 为 CSV／地理表格、文本／十六进制分页、书籍、XMind 和图片翻页提供内容区底部居中的悬浮胶囊。标题、目录及工作表导航独立保留；滚动内容末尾留出可读空间，书籍中的源分页操作条错开显示。GPUI 胶囊使用主题半透明、边框和阴影，尚未实现背景模糊或光学折射。

`native/FloatingReaderToolbar.swift` 为图片／SVG、PDF、媒体、字体、SQLite／XLSX 和 Office 提供对应的原生容器。支持的 SDK 构建通过 `GLIM_NATIVE_GLASS` 开关在 macOS 26+ 使用公开的 `NSGlassEffectView`；旧 SDK／旧系统使用 `NSVisualEffectView`，最低系统仍为 macOS 11。过宽操作条可横向滚动，媒体操作避开 AVKit 播放控制。SVG 继续使用隔离的流式图片文档，原生按钮只调用应用包装页的图片命令。常用原生工具栏移除文件字节和查询超时重试操作，后备阅读器继续保留完整字节分页；对应的无用字节操作轮询桥接也已移除。可见控件按文字及选择器测量宽度，溢出由悬浮条滚动视口处理。 阅读操作条隐藏时不显示图标，鼠标在底部宽透明区域停留后显示，移出后延迟隐藏；按键拖动期间冻结显隐，结束拖动不触发展开。原生透明感应区不拦截文档点击。操作条按可见内容收缩，按钮使用带边界的表面，与次要色状态说明区分；行列翻页组仅在需要时出现。

## 模块与依赖方向

```text
crates/
  glim-core/src/       文档／Git／更新数据、diff 解析和历史图布局；无 I/O 和 GPUI
  glim-services/src/   文件系统、Git、监听、格式解析、备份和偏好；无 UI
  glim-app/src/
    app/              启动、动作、菜单、语言、图表引擎和更新协调
    views/
      workspace/      窗口、标签、加载、导航、编辑和更新会话恢复
      reader/         原文、排版、数据树／表、图片、原生预览、XMind 和差异
      changes/        仓库操作、Changes 和 Graph
      explorer.rs     按需目录树、置顶祖先与完整名称／路径浮窗
      split_diff.rs   对齐差异和同步滚动
      minimap.rs      文档概览
native/               内嵌 macOS 预览、设置辅助程序和 Sparkle 桥接
assets/               品牌、文件图标、语法查询、离线引擎和包元数据
scripts/              打包、签名、更新清单与专项原生检查
```

依赖单向：`glim-app → glim-services → glim-core`，app 也可直接依赖 core。固定 GPUI Kit、保留 Cargo.lock。阻塞文件／Git 工作走后台执行器；render 只组合缓存状态，不扫描目录或执行命令。视图持有实体、订阅和可取消任务句柄。

## 阅读边界统一管理

`assets/reader-limits.json` 是应用阅读阈值的唯一数值来源，按阅读器分类，注明类型、单位、超限效果和说明。`scripts/generate-reader-limits.py` 校验配置，在各 Cargo OUT_DIR 生成 Rust 常量、Swift ReaderLimits 和嵌入式 JSON。`glim-services::limits` 导出 Rust 值，应用展示层直接使用；原生预览编译生成的 Swift，私有图表 WebView 接收同一份值映射。构建跟踪配置及生成器变更，CI 路径过滤也覆盖两者，阅读器不在运行时读配置文件。见[自动生成清单](reader-limits.zh-CN.md)，用生成器的 `--docs` 更新。非 Git 阅读器以流式、分页或完整源后备替代文件总量门槛；工作预算约束活动处理，不限制完整文件访问。Git/diff 留待专项迭代。

## 工作台与编辑

每个窗口拥有独立的隐式工作空间。添加文件夹会按顺序追加根目录入口，允许相同路径重复添加，也允许父子目录并列；其他窗口可添加同一文件夹。Explorer 按根目录入口区分展开、选中及元素身份，窗口内按路径共享目录数据。Git 仓库仍按仓库路径去重。顶层根目录的右键菜单可移除单个入口，不删除文件、不关闭已打开的标签。Explorer 发送稳定的根目录身份，Workspace 同步更新根目录、搜索范围、最近记录、仓库扫描及文件监听。移除最后一个根目录后仍独立监听已打开文件，并从最近记录移除空工作空间。

Workspace 管理标签、Explorer/Changes 实体、导航历史及异步加载。普通标签以路径为身份，差异／历史标签还包含仓库、范围和提交。重复打开激活已有标签／窗口。Finder 打开的所有格式共用保留队列，错误也在标签中显示。

工作空间界面沿用现有灰阶主题令牌：开始／文件导航位于紧凑侧栏（默认窗口宽度的 20%，双击分隔条恢复默认比例，拖到 120 px 以下自动收起，最大宽度为窗口的 50%），Git 和侧栏设置入口暂时隐藏，主体内容直接从文档标签开始，单文件也显示标签。`workspace/toolbar` 集中管理外围工具栏的动作定义、阅读器能力选择、顺序、图标、提示、选中／可用状态、统一按钮渲染和动作分发；依次呈现导航、文档视图／布局操作、更新入口。阅读器暴露自身能力，工具栏不另建文件扩展名白名单。侧栏／后退／前进操作位于外围标题栏的 Glim 名称和分隔线之后，阅读模式与换行操作位于右侧，统一使用同尺寸图标按钮。标题栏同时负责侧栏显隐；搜索输入框常驻窗口中间，结果列表在输入框下方展开。保存通过自动保存、菜单与 ⌘S 完成，不显示保存按钮或底部保存状态。Git 仓库状态及仅提交暂存内容的提交区属于更改面板，不设置常驻工作空间底栏。所有操作复用现有阅读器实体和异步保存／Git 流程。`app/menus` 集中定义 Glim／文件／视图三个 macOS 菜单；关于、设置及刻意与设置页重复的检查更新入口位于 Glim 菜单；刷新保留快捷键，文件菜单的“关闭窗口”仅关闭当前工作空间，⌘, 打开当前工作台的设置。`workspace/settings` 提供主题、语言选择，以及默认文件类型管理、检查更新和快捷键说明；语言选择由应用缓存，渲染时不读取偏好文件。主题提供跟随系统／浅色／深色选择。服务层保存外观偏好，应用串行写入；每个工作台保留外观观察订阅，选择跟随系统时响应 macOS 外观变化。侧栏密度与阅读字号固定，普通文本默认自动保存，不提供相关设置开关。开始和设置页隐藏原生阅读器视图，不销毁文档标签。

开始页以文件夹名称和路径列出最多 30 个最近使用的非空文件夹工作空间。列表隐藏当前窗口的工作空间。点击已打开的工作空间会切换到对应窗口（包括根目录仍在恢复的窗口）；尚未打开时才新建窗口，恢复按顺序保存的根目录（含重复项），不恢复文件标签。匹配依据历史身份或完整有序根目录列表，保留重复根目录的数量。服务层将历史原子保存到 `recent-workspaces.json`，首次读取时迁入旧版保存的最后一组文件夹。App 管理共享缓存及串行后台偏好任务，开始页只渲染缓存数据。每个窗口添加文件夹时更新自身历史记录，相同的文件夹列表共用一条最近记录。

文档工具栏提供窗口内的文件全屏：隐藏侧栏、标签和历史摘要，展开当前阅读器，并保留含查看控件及退出按钮的精简标题栏。Escape 可退出。侧栏尺寸、可见状态和阅读器实体均保留，macOS App 全屏独立工作。

关闭工作空间窗口只影响当前窗口，并保留未保存修改的确认保护。应用采用显式退出模式：最后一个窗口关闭后 Glim 仍运行，点击 Dock 图标可重新创建窗口。“文件 → 关闭窗口”（⌘⇧W）关闭当前窗口；⌘W 关闭当前标签或空窗口。仅“退出 Glim”／⌘Q 请求退出整个应用，保留已有更新安装退出检查。

工作空间根目录原子保存到 `workspace.json`。普通启动恢复最近目录，不提供完整的通用标签会话或未保存草稿恢复；更新重启另有一次性标签会话，见[应用更新](auto-update-design.zh-CN.md)。

刷新在支持范围内保留阅读状态，绝不替换有改动的草稿。导航后旧任务结果被忽略；已经执行的阻塞工作可能完成，但不再安装其结果。监听器合并事件，并监听 linked worktree 的 Git 元数据。横向内容滚动优先于导航手势。

`SourceReader` 长期持有 `EditorState`，支持输入、选择、撤销／重做、搜索和折叠。Tree-sitter 处理已有 grammar，其他配置／模板使用可见行词法着色，不引入 LSP。自动保存按文件排队，约停止输入 800 ms 后触发，保留 ⌘S/Ctrl+S。同目录临时文件提供原子替换；磁盘基线冲突时保留草稿，关闭／退出检查未保存内容及保存任务。

`reader/markup` 使用 TextView 排版 Markdown，使用嵌入式 WebKit 渲染 HTML，预览与源码共享编辑状态。按格式保存偏好，刷新／重开保持模式，原文未变时复用渲染状态。HTML 预览从编辑器快照渲染 CSS 和 JavaScript，并保留源码编辑入口。JSON/CSV 实体通过保留的后台任务解析编辑器快照，只读投影不会替代可编辑原文。 `services/markdown_preview` 在准备 Markdown 预览时兼容显式管道表格的表头、分隔行及同列数数据行之间的空行，使用顶层 Markdown AST 区块范围避开代码、HTML、数学公式和 frontmatter。仅调整预览文本，编辑器及保存的源文件保持原样；图片、图表及标题导航使用同一份预览文本。 CSV 与 TSV 共用持久化阅读模式偏好 `csv-view`；新建普通或分页阅读器沿用上次选择的表格／源码模式，已有阅读器刷新时保留自身模式。未能切换成功时不更新偏好。 以表格模式打开 CSV/TSV 时，工作空间在读取文件期间隐藏旧文档，在主区域居中显示预览加载提示；表格阅读器解析及分页加载期间使用同一提示。保留已有阅读器实体，失败后沿用正常的错误视图。

## 图表与格式阅读器

`services/markdown_preview` 解析并去重图表／公式，调用私有 `--render-markdown`，再将有界 SVG 转为图片。`app/diagram_engine` 在进程主线程使用 WebKit 和内嵌离线引擎。结果增量发布，取消会终止渲染器。macOS 使用后台 `GlimRenderer.app`（`LSUIElement=true`），非打包构建沿用可执行文件的渲染模式，不依赖 Node、Java 或远程服务。

Mermaid、Graphviz、PlantUML、flowchart.js、WaveDrom 和 MathJax 及许可证均内嵌；本地 Salt/Chen 适配器仅覆盖部分语法。禁用图表外部资源、导航和下载，失败时保留源码。引擎维护见 [assets/markdown/README.md](../assets/markdown/README.md)。

`services/formats`、`text_formats` 与 `vector_formats` 提供有界容器目录／文本提取、基础阅读投影和静态网格／位图字体图片，专用电子书阅读由 `services/books` 和 `reader/books` 提供，通用投影不执行文档代码。`services/media` 负责有界图片解码。独立打开的大 PNG 复用 `services/inline_images` 的 ImageIO 缩略图准备，通过已读取字节的临时快照保持预览与指纹一致；工作台加载期间立即显示状态提示。其 `GifPlayback` 保留顺序解码器和有界合成／恢复缓冲区；`reader/media::GifReader` 持有可取消的播放任务，逐帧直接向 GPUI 提供 BGRA 像素并释放旧纹理。GIF 按原分辨率合成，显示帧最长边限制为 2048px；按绝对时间轴播放，使用两个预取批次（每批最多三帧／16 MiB），落后的中间帧不上传纹理，保留帧处置和有限循环语义，不走 GPUI 的整段动画缓存；隐藏标签暂停解码，关闭取消任务并释放纹理。各阅读器预算和边界见[格式与限制](file-format-support.zh-CN.md)。

`services/xmind` 从有界 ZIP 正文中读取新版 JSON 或旧版 XML，不提取附件；不依赖 UI 的工作表／主题模型包含备注、标签、游离根和关系端点。`reader/xmind` 持有工作表选择、折叠、缩放、滚动和详情；缓存布局，使用 GPUI 主题绘制可见节点／连接。阅读器只读，复用普通加载、刷新及更新会话路径。

## 内嵌 macOS 预览

`native/Preview.swift`、`EmbeddedPreview.swift` 和 `SQLitePreview.swift` 将 PDFKit、AVKit、Quick Look、CoreText、工作表 WebView 和 SQLite 视图内嵌到标签，不启动独立预览应用或 Dock 图标。app build.rs 编译 Swift 静态库。`reader/native_bridge` 是限定主线程的窄 unsafe FFI 边界，将 NSView 挂到 GPUI AppKit 窗口；原生预览、右键菜单与更新桥接是 app 的限定 unsafe 例外，其余 app deny unsafe，core/services forbid unsafe。

`services/matroska` 在后台检查有界 EBML 结构，将 H.264／AAC-LC 样本无损重新封装为临时 MP4，交由 AVKit 播放。AVC 参数集来自轨道配置或 Annex-B 帧，MP4 合成偏移保留帧重排。`services/preview` 保留临时媒体并映射原始路径到播放路径，保持文件身份和显示名称。无需安装或启动 FFmpeg，支持范围及预算见[格式限制](file-format-support.zh-CN.md)。

`services/preview::prepare` 在后台校验文件，准备播放列表、数据库快照和磁盘工作表索引。每个 `reader/native` 实体保留控制器及准备数据。系统框架加载通过主线程队列调度，不在 GPUI render/layout 中读取文件。切换隐藏视图并暂停媒体，保留当前页码／播放位置；关闭先释放原生资源，再清理临时数据。工具包浮层暂时隐藏原生视图，可访问性节点和 responder chain 动作接入主窗口。

SVG 图片在服务层清理后复用 `HTMLPreview` 和流式本地资源处理器，以静态图片显示；单一滚动容器提供适应窗口、实际大小及缩放控件，不执行 SVG 脚本或链接。栅格图片继续使用 ImageIO。图片预览不再显示文件字节底栏。栅格滚动容器在图片小于可视区域时双轴居中，适应窗口模式随视口调整重新计算。文件树和文档标签右键菜单通过独立的 `views/native_menu_bridge` AppKit 桥接显示，异步返回选择结果，所属实体释放时取消。菜单直接位于原生预览之上，不隐藏、暂停或替换阅读器；只有明确选择的动作才改变文件／工作区状态。 浏览器图片预处理保留 data URI 图片（含内嵌 SVG，不转为位图）、XHTML `foreignObject` 标签和完整样式表，SVG 图片沙箱阻止文档脚本及外部资源加载。百分比／缺失的根尺寸按 viewBox 或另一绝对尺寸推导，再用于缩放计算。

PDF 与 Office/iWork 保持只读。`services/spreadsheet` 将 XLSX 关系、共享字符串及工作表 XML 流式写入临时 SQLite 索引，另以磁盘位置索引按行列页生成展示工作簿，由原生 Quick Look 的全尺寸 normal 样式呈现单元格样式、列宽、行高、合并与缓存值，预览视图四边约束到阅读区，不重算公式。完整地址／值／公式索引作为内部资源保留，不提供独立数据模式。展示副本不包含图表及绘图，共享字符串保留文字但不保留分段富文本格式；私有应用辅助进程负责可取消的分页生成。XLS 及不支持的结构使用 Quick Look。字体仅查看，不安装。音频封面／元数据异步读取并可取消，装饰播放动效遵守减少动态效果设置，不代表真实频谱。

`services/sqlite` 流式复制数据库／WAL／journal 并检查源状态，副本重建 SHM。原生 SQLite 在串行后台队列执行生成的只读查询，禁用扩展加载，不 checkpoint 或写入源文件。缺少主库的 sidecar 仅显示有界信息。

`native/PreviewMain.swift` 只用于独立的默认文件类型设置辅助程序。明确选择并确认后才修改 Launch Services 处理程序，记录旧处理程序；恢复时不覆盖用户之后的修改。

## 目录发现与 Git

Explorer 新增根目录时默认展开一层，内部子目录保持折叠；普通工作区恢复和更新会话恢复从 `explorer.json` 恢复各根目录的展开状态，原子串行写入，退出时等待写入完成。激活标签时通过保留的后台任务逐层加载祖先目录，展开并定位当前文件，以最后请求的文件为准。Explorer 展开时只读取直接子项，遵守 ignore，隐藏 `.git`，不递归跟随软链接。后台媒体检查缓存控制文件夹播放菜单，render 不扫描目录；空白区域与行级菜单分开。

仓库发现在后台扫描所选根目录，不使用任意时间／深度／数量截断。排除生成目录和忽略目录；自动从主目录发现时跳过 macOS Library／废纸篓，明确选择这些路径时仍扫描。单路径失败不丢弃其他仓库；诊断有界且去重，监听刷新不反复弹警告。

Git 使用参数数组和 literal pathspec，清理仓库位置环境覆盖，禁用 external diff/textconv/pager/fsmonitor，输出有界且独立排空 stderr。沿用用户凭据、hooks 与提交签名。暂存操作显式执行，提交只包含 index。

写操作前服务重新检查 HEAD/index/源状态。应用内编辑和 Git 写入锁保护各窗口草稿，不构成与其他 Git 客户端之间的事务。Pull 仅快进，删除分支使用 `-d`，不增加克隆、强推或破坏性历史重写。

Core 根据提交及父提交 ID 计算 Graph 通道，每次增加 200 个提交、最多 1000 个；未变历史和重叠刷新保留行及滚动状态。合并预览比较第一父提交，冲突 combined patch 回退单栏。差异显示预算不会改变整文件暂存。双栏按原行号对齐并同步纵向滚动。

## Markdown 网络图片

`app/image_http` 提供仅支持 GET 的 GPUI 图片传输，网络与解码通过 `services/markup_images` 在后台执行。网络使用共享超时、重定向及最低传输速度策略；响应流式写入临时文件，不设总下载大小门槛；使用系统 curl，SVG 使用系统字体并禁用外部引用，失败时显示占位图。GitHub 仓库的 `blob`／`raw` 图片地址转换为原始文件地址；常规 ref/file 地址在原始域名失败时回退到 GitHub Contents API 的原始媒体响应，两个请求共用时限。未认证的 API 回退受 GitHub 请求频率限制，不改变原文或普通链接的目的地。

`reader/pictures` 在后台解析真实图片引用，忽略代码示例，按主题选择 `<picture>` 候选，并为每个解析后的 `.gif` 地址（本地或 HTTP）保留一个逐帧播放器，重复引用共享。图片解析回调始终使用自定义 GPUI 图片源，包括初次加载期间，避免误走整段 GIF 缓存。删除引用会释放播放器，隐藏标签和源码模式取消播放任务并释放解码缓冲，只保留 GIF 压缩数据；返回时未完成动画重新播放，已完成的有限循环 GIF 保留最后一帧像素；渲染中不执行网络或文件 I/O。


`services/inline_images` 通过 macOS 自带的 `sips`／ImageIO 串行准备静态内嵌图片缩略预览，最大边长 2,048px；Rust 只解码有界缩略图，避免完整大图像素缓冲常驻查看器。远程内嵌位图在有界下载后使用同一路径，本地 SVG 沿用有界栅格服务。`reader/pictures` 为每个静态图片地址保留一个 `InlineImageReader`，只激活当前主题候选；隐藏或切换源码会取消准备并释放像素。内嵌预览放大时可能损失细节，原文件和单独图片阅读器限制不变。图片图集释放延后到渲染窗口重新回到 App 后执行，确保当前窗口纹理也被清理。

## 电子书阅读

`services/books` 读取有界 EPUB 元数据／spine 与 EPUB3 nav 或 EPUB2 NCX、FB2／FB2 ZIP 结构及嵌入插图、自然排序的 CBZ 漫画页。章节在后台加载和净化；拒绝 XML 实体声明、压缩包路径越界、脚本与自动外部资源加载。图片按章节限制编码／解码预算，资源仅保留在内存，不提取到文档目录。

`reader/books` 跨 render 保留章节解析实体、资源图片、焦点／滚动句柄和可取消加载任务。阅读页提供衬线／无衬线字体、字号、行距、页宽、纸张色、目录、章节／翻页导航、书签及位置恢复。偏好通过保留的任务和合并状态缓冲区串行写入；更新退出检查等待阅读偏好写入。`books/preferences` 按内容指纹在应用偏好目录保存书籍状态，不改写原书。

### 统一界面翻译

`glim-services::locale` 统一管理 Rust 界面及传给原生预览的翻译数据。英文消息作为唯一键，`assets/locales/en.json` 提供回退，每个语言文件使用相同键，并用 `__language_name` 指定语言名称的消息键。服务构建脚本自动发现并内嵌语言文件，设置页自动生成语言选项。新增完整的 `<BCP-47-code>.json` 即可加入语言，无需修改语言分支。跟随系统优先匹配完整语言代码，再匹配语言，最后回退英文。

构建自动运行 `scripts/check-locales.py`，检查重复键、语言键集、空翻译、占位符、Rust／Swift 字面量消息引用，以及英文翻译中的中文。应用标签和生成的预览说明使用统一字典；用户内容、路径、应用名称、语言／格式名称及技术诊断保留原文。原生控件使用 `L`，Rust 使用 `locale::tr`；动态消息保留命名占位符，HTML 输出转义翻译。GPUI 组件内部控件使用组件库自己的语言支持；应用语言文件不负责翻译第三方组件内部控件。

### 可恢复的文件删除

`workspace/file_operations` 负责移到废纸篓前的确认，并复用跨窗口文件变更锁，避免自动保存和 Git 操作与删除并发。成功后关闭各窗口中受影响的当前文件标签，移除对应工作区根目录。文件树和普通文件标签的右键菜单提供该操作；“从工作区移除文件夹”仍是独立的不修改文件操作。`glim-services::workspace::trash_entry` 在后台执行，持有保存互斥锁，调用内置原生辅助程序的 `--trash` 模式。Foundation 的 `FileManager.trashItem` 负责支持恢复及不同磁盘卷的移入废纸篓操作，不跟随选中的符号链接，也不回退到永久删除。

ImageIO 图片预览等待嵌入视图挂载且滚动视口尺寸有效后才执行首次适应缩放。解码和首次布局期间共用居中加载提示，避免零尺寸视口将图片缩到几乎不可见。

### 浏览器式 HTML 预览

`reader/markup` 为 HTML 保留 `NativeReader`，同时保留普通源码编辑、保存和阅读模式偏好。以源码模式打开时，直到请求预览才初始化 WebKit；切回预览使用当前编辑器快照。`native/HTMLPreview.swift` 持有 WKWebView，负责 CSS/JavaScript、页内锚点和加载／错误提示。使用非持久化网站数据存储隔离预览状态。本地链接经原生桥返回 Glim 已有的文件／URL 导航，不会在源码标签不变时悄悄换成另一份文档。弹窗遮挡和切换标签时隐藏原生视图。

私有 `glim-html` URL scheme 提供编辑器快照，不在用户项目目录生成临时 HTML。本地资源由可取消的串行后台读取器按共享 IO 缓冲预算分块加载；解析符号链接后的资源路径必须位于所属 Git 项目内；未找到 Git 根目录时沿用文档目录。根目录在资源后台线程查找并缓存，同项目中通过 `../` 引用的同级目录样式和脚本可正常加载，不阻塞原生布局。网络资源交由 WebKit。该 scheme 与普通 HTTP 源不同，需要后端、安全源 API、浏览器扩展或任意文件系统访问的页面，可能仍需开发服务器或完整浏览器。大 HTML 由同一资源后台线程流式读取原文件，不构造完整编辑器快照；保留可编辑源分页，修改当前页后须先保存再返回预览。WebKit 仍自行管理 DOM 和脚本内存。这一路径独立于 Markdown 的静态内联 HTML 和隔离的离线图表渲染。

## 诊断日志与文件故障隔离

`glim-services::diagnostics` 在 `~/Library/Logs/Glim/` 中通过有界后台队列写日志，按本地日期归档，单个文件达到 8 MiB 前滚动，最多保留 14 个日志文件（包含当天分段），启动及滚动时清理旧文件。普通日志不阻塞绘制；panic 请求落盘并等待最多两秒确认。记录启动版本、文件打开/读取/读者初始化、标签切换、保存及工具包 Info/Warn/Error 信息；panic 额外记录所属文件完整路径、阶段、线程、源码位置和强制捕获的堆栈，不记录文件正文。普通队列满时可能丢弃诊断事件。

`reader::boundary` 为文件子树的延迟布局、预绘制及绘制标记文件上下文，panic hook 在当前进程中隔离故障路径。固定版本 `gpui-pre` 0.3.8 的本地补丁（`vendor/gpui-pre/GLIM-PATCH.md`）在进入 macOS 回调边界前捕获已确认的文件绘制 panic，恢复实体借用、更新层级和布局引擎，丢弃未完成帧及绘制栈并强制重绘。故障文件显示完整路径、重试及打开日志按钮，其他标签及未保存的编辑实体继续保留。文件读取和读者构造的 unwind 转换为文件错误。仅显式重试，重启后解除隔离。abort 模式 panic、内存耗尽、栈溢出、原生异常及非文件应用 panic 不属于该 unwind 边界。

### 非 Git 阅读器的可扩展处理

`services/geo` 流式分页读取 GPX/KML；`services/xml` 为地理及 XLSX 阅读统一处理 XML 字符引用。`services/paged` 管理可编辑 UTF-8 分页和可取消的原子区间替换，刷新保留当前页及未变的编辑状态。`services/streamed` 在取消后重建解码器，并使用有界滚动缓存。大型单元格和结构文本通过字节窗口或磁盘源分页访问。图表分批渲染；书籍复杂章节保留导航并提供完整文本／十六进制资源分页。图片串行解码，在解码内存预算内缩放栅格，保留逻辑尺寸和完整源字节；这不是真正的原分辨率分块解码。SDK 临时分配、ZIP 中央目录索引和 SQLite 表达式计算仍受平台／库实现约束。Git/diff 优化另行处理。

Markdown 预览使用 TextView 的固定视口虚拟块列表，替代全文自然高度控件；表格规范化仅在存在空行分隔的管线表格候选时建立 AST；图片与图表扫描在缺少必要语法标记时跳过 AST。首次预览在插件配置后才提交正文，图表与公式资源独立于解析修订更新，避免重复全文解析。后台解析完成前显示居中加载提示，状态完成后刷新阅读器。缩略图导航与位置跟踪使用同一虚拟列表，锚点使用组件内置范围定位。屏幕外的块按需排版；单个超大块仍受组件块级布局实现影响。

共享调度方向、格式专属中间表示、当前能力和待迁移项见[渲染管线](rendering-pipeline.md)。图表批次先识别引擎依赖，再按需并发导入离线 ESM 模块；字体使用内存映射，成功栅格结果使用有界进程内缓存。应用构建时内嵌完整模块清单，运行时不扫描项目目录寻找引擎。

Markdown 的工作区刷新会在后台核对引用的本地静态图片元数据，即使 Markdown 正文本身没有变化。图片改变时重新解码，新帧准备好后替换旧帧；历史阅读器和远程图片不参与该文件系统刷新。

Office 和工作簿的外部打开操作在点击时重新查询系统默认应用。默认应用为 Glim 时，提供兼容应用列表和应用选择器，按 bundle identifier 排除 Glim 的所有副本；选择器结果也再次校验。使用明确的应用 URL 打开文件，不更改文件关联。

`services/word_preview` 使用系统 textutil，在串行、可取消的子进程中生成 DOC／DOCX／RTF 的只读阅读投影；HTML 落盘后按固定 IO 缓冲和共享活动记录预算流式修饰。字号转换为相对阅读字号，保留段落、列表和强调，正文使用完整视口宽度。`native/WordPreview.swift` 通过禁用文档 JavaScript、非持久化的 WebKit 提供单一自适应预览、放大／缩小、百分比和重置，不再提供模式选择器；准备或加载失败时自动回退 Quick Look。原生控制器先关闭，再清理投影目录。自适应预览会改变分页，复杂表格、绘图、嵌入对象、页眉页脚和字体还原可能有差异。系统导入器及 WebKit 内部分配仍受框架实现约束。Pages 保留 normal Quick Look，幻灯片保留 compact 无装饰样式。

共享阅读操作保持相对顺序：内容选择、翻页导航、格式辅助操作／状态、复制与识别、外部应用打开。办公文档保留单一预览，工作簿移除“单元格数据”入口，完整地址／值／公式索引作为内部资源保留。不可用操作可隐藏，其余操作不重新排序。

### 预览复制与内嵌图片识别

`native/PreviewCopy.swift` 为 Office／iWork 和 PDF 提供复制入口，非表格预览另提供“识别图片文字”。Word 由宿主读取 WebKit 已选文字或正文，文档脚本仍禁用；PDF 复制选区或当前页文字。XLSX／XLSM 从完整磁盘单元格索引读取当前工作表、当前预览行列页的缓存值，输出保留空单元格及行列顺序的 TSV，对制表符、换行和引号转义，不抓取工具栏或依赖 Quick Look 文字。查询在串行队列使用只读 SQLite 连接，可在换页、隐藏、关闭或重新复制时中断。Excel／Numbers 不展示图片识别入口。其他原生提供器通过公开辅助功能接口提供当前文字／单元格，包括字符串、数值和富文本；文字可用性仍依赖提供器。输出不包含表格样式，不提供可编辑工作簿或演示稿导出。

Apple Vision 在本机识别图片。PDF 仅在共享图片工作预算内栅格化当前页；旧版 Word 阅读可识别当前可见画面。OOXML／iWork 内嵌图片使用磁盘成员清单，按需解出一张位图，结果窗口提供“下一张图片”和“复制全部”。不整体展开归档、不保留所有图片、不增加文件总大小门槛。隐藏或关闭阅读器会取消子进程和识别，并丢弃旧回调。旧版二进制 Office 内嵌图片和不支持的矢量资源不走该提取路径。

启用宏格式的 XLSM 与 XLSX 共用流式 OOXML 工作表索引和分页预览。仅读取工作表值、已保存的公式结果及展示资源；不执行 VBA，也不将 VBA 项目复制进展示工作簿。XLSM 同时加入 Finder 候选打开类型和 Excel 默认文件类型分组。

`views/path_hint` 在主线程管理文件树截断标签和文档标签页的原生路径提示句柄；`native/EmbeddedPreview.swift` 使用不抢焦点的子面板，将提示显示在嵌入式文档视图之上，不隐藏或重建阅读器。提示统一显示图标、文件名和可换行的路径，限制在屏幕范围内；移出、拖动、点击、滚动、键盘输入及窗口变化时关闭。悬停范围来自 GPUI 布局，拥有者释放时取消待显示面板和事件监听。

Markdown 图表与公式节点保留语法身份，可见时将资源加入有界后台队列。结果更新共享 LRU 缓存并仅使行内布局失效，不重解析正文；无需手动切换图表页。隐藏预览时取消任务并释放阅读器图片缓存，编码／解码与待处理键值受共享策略预算管理。

### 演示文稿播放

PPT、PPTX 和 Keynote 的原生 Office 工具栏提供“播放幻灯片”。`NativePreviewHost` 保持 Quick Look 所属的 NSWindow 不变，在原窗口进入系统全屏时将文稿铺满工作区内容。Esc 或“退出放映”恢复原阅读区域；原本已全屏的窗口保持全屏，原本普通窗口则退出系统全屏。通过窗口大小、全屏退出和窗口关闭通知同步布局与生命周期；隐藏或关闭阅读器会清理监听。不对活动的 QLPreviewView 使用 NSView 视图全屏或跨窗口迁移：迁回时 Quick Look 的 activate 可能触发断言崩溃。文稿内导航、动画及内嵌媒体仍取决于系统提供器。

右上角的内容全屏操作同时进入系统窗口全屏并收起侧栏、标签和 header，Esc 退出。记录进入前的窗口全屏状态，退出内容全屏时不改变原本就处于全屏的窗口。阅读器实体和预览状态持续保留。Office 放映期间将 GPUI 同级表面设为透明，退出恢复，从而移除应用 header；Quick Look 的窗口归属和视图层级保持不变。

PDFKit 和 Office/iWork 放映共用 `SlideshowInput`。上／左／Page Up／Shift+空格后退，下／右／Page Down／空格前进，Home/End 请求首末页，Esc 退出。标准键盘式翻页器复用此映射，消费类媒体 HID 按键不作映射。无修饰键的文稿单击前进；拖动、重复双击、原生控件、悬浮工具栏、辅助功能公开的按钮／链接及 PDF 链接注释除外。按下和释放成对消费，避免原提供器再触发一次。PDFKit 直接执行页操作；Quick Look 优先按系统控件语义标识调用公开的 Previous Page／Next Page 辅助功能按钮操作，禁用按钮在边界处不作操作。不提供这些按钮的提供器才接收规范化导航按键，不重新进入本地事件监听。导航能力仍依赖系统提供器。HTML 脚本保留自身快捷键，普通图片、媒体和文本阅读不加入放映映射。

Office 阅读器可用 F5 进入放映。PPT／PPTX／Keynote 的“上一页／下一页”工具栏按钮在普通预览和放映中均可使用，共用导航适配器；只有“播放／退出放映”的显示取决于放映状态。导航按需遍历当前提供器的辅助功能控件树并防止循环，不依赖文档名称、页面文字、缓存的界面索引或预加载整份幻灯片。放映时将 GPUI 同级表面设为透明而不隐藏宿主视图，保留窗口可见性和输入路由，退出后恢复原透明度。

支持实况文本的 macOS 13 及更新系统，在位图上附加 VisionKit 选字层，异步分析当前已校正方向的预览像素，通过取消任务和代次检查丢弃旧结果。选字层随图片缩放，支持系统文字选择和复制；非文字区域以及按住 Option 的拖动传给原有图片拖动逻辑。SVG 不走该路径；旧系统保留“提取文字”。

### PDF 幻灯片放映

普通 PDF 阅读默认“适应宽度”。`ReaderPDFView` 根据滚动视口、PDFKit 页面间距和旋转后的页面几何计算缩放，并处理双页布局。此模式下窗口布局、当前页变化会重新适配；缩放按钮、捏合和“原尺寸”退出自动适配。中文右键菜单另保留“适应整页”。放映视图继续使用 PDFKit 整页自动缩放。

PDF 工具栏启动 PDFKit 单页全屏放映，复用已打开、已解锁的文档，从当前页开始。方向键、Page Up/Down、空格与 Shift+空格以及 Home/End 用于翻页；Esc 或“退出放映”返回最后展示的页，并保留阅读器的缩放模式。退出、隐藏或关闭阅读器时清理键盘监听和页码通知。页面按需渲染，不预生成整份文档的图片数组。

### 图片文字提取

图片预览提供中文“复制图片”右键操作，图片阅读区域取得键盘焦点时支持 ⌘C／Ctrl+C，实况文本选区优先复制文字。单页 PNG／JPEG 保留源文件编码；其他位图将完整的当前解码页复制为 PNG，不受视口裁切和缩放影响；SVG 同时提供原始矢量数据和 PNG；独立的 WebKit 预览按适应窗口渲染完整图片，不改变当前阅读区域的缩放或滚动位置。PNG 使用阅读视口的渲染分辨率。编码和文件读取在串行后台队列执行。换页、隐藏或关闭取消旧复制，通过代次和剪贴板变更计数检查避免覆盖更新的剪贴板内容。剪贴板传输和接收应用的格式支持仍受系统约束。

`ImageTextExtraction` 从图片工具栏按需调用本机 Apple Vision，在共享串行队列识别当前页已校正方向的预览像素，复用图片解码的工作内存策略，不重复解码完整原图。阅读器持有可取消请求，切页、隐藏、关闭或重新识别时取消旧请求并通过代次检查丢弃旧结果。子窗口显示可选中的纯文本并提供“复制全部”，图片拖动保持独立。目前覆盖 ImageIO 位图预览，不覆盖 SVG/WebKit 图片。识别使用当前预览分辨率，超大图片中的小字可先切换“原尺寸”再提取；识别可能有误，不保留文档排版。

### 阅读器操作入口

`views/workspace/reader_actions.rs` 管理 GPUI 文档操作描述（标识、标题、图标、选中与可用状态）。工作区工具栏、预览内容右键菜单共用按阅读器能力生成的列表和分发器。源码编辑器继续使用统一且感知选区的剪切／复制／粘贴／全选菜单；预览操作只挂在内容区，不作用于标签和导航区。

`native/ReaderActions.swift` 管理原生阅读器控件描述、菜单策略和内容区右键路由。格式通过有序的 `ReaderControls` 向 `FloatingReaderToolbar` 注入控件；Word 和工作簿使用语义标识，已有堆栈式阅读器通过适配入口接入。可用、选中、隐藏状态直接来自原控件。菜单调用原按钮，保留依赖 sender 的操作；工作表选择器映射为子菜单。状态文字不会成为菜单命令。共享工具栏继续负责测量、玻璃外观、溢出和悬浮行为。

有工具栏的原生阅读器从控件集合生成内容右键菜单。PDF、图片通过同一路由和菜单策略提供专用操作。菜单打开时读取状态，标题由格式侧本地化；排除工具栏命中，禁用系统菜单插件并清除外部 Services／Writing Tools 注入。路由弱引用视图，销毁时移除事件监听，不替换或截图当前阅读内容。嵌入式 HTML 页面和系统媒体播放控件保留自身交互，不额外生成占位工具栏。
